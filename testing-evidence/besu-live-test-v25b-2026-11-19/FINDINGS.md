# Findings, round 1b

No contract bug was found in the tested bytecode; `contracts/` was not modified by the test agent.

- **F-1 (HIGH, process).** `contracts/ValidatorsRegistry.sol` changed during the run (`07d61fd`, `a673ff3`). The tested bytecode is the pre-`07d61fd` one, so BH-03 is stale for the current tree and the two-step operator change has no Besu evidence. A later round must test `proposeOperator` -> Verifier `confirmOperatorReady` -> QBFT switch.
- **F-2 (low, Besu; repeat of round-1 F-1).** `IllegalStateException: Failed validator smart contract call: unable to execute call at block 249` (EventMultiplexer ERROR, one BFT message dropped) occurred once on the late-joining node n2b during BH-03, right after "Block 248 is already imported": 1 time in about 450 blocks, no effect on block time. Zero times on Net-T and on the other Net-A nodes. Same race as round 1.
- **F-3 (info, cosmetic).** `seatTransferPending` is not cleared on the SELLER after a transfer (BH-06B: still true for the first buyer after selling to the second). The seller has no record so it has no effect, but the seller could still call `acceptSeatTransfer` and emit an event. Consider deleting the flag for `from` in `onSeatTransferred`. (Also check what happens to `pendingOperator[from]` of the new two-step reservation map in `onSeatTransferred`.)
- **F-4 (info, design).** Transfer of an Active seat keeps `getValidators()` byte-identical; a Probation seat keeps its `periodStartedAt`, so a bought Probation paid-entrant seat can be activated at the original time (verified). An Active seat that is transferred re-checkpoints: the buyer cannot vote on proposals created earlier (verified on a real Registry parameter proposal). Reward attribution across seat transfers still needs event history (decided: event replay).
- **F-5 (info).** Probation board-seat holders are visible as seat holders (`isBoardMember` true, `getBoardSize()` 5) but `hasBoardAuthority` is false; a vote of 3 needs three ACTIVATED founders. With only two activated, a proposal stays at 2 of 3 (verified). Until a third founder is activated no board action can execute. Operational note for the genesis plan.
- **F-6 (info).** Start-up noise with no effect: n5 logged "Error importing pending blocks / Invalid block 4 / Parent block not present" in its first seconds; nC on Net-T logged "Chain download failed. Restarting after short delay" at first sync.
- **F-7 (info, carried).** f=1 round changes cost 12 s (every 3rd block at n=4 with one node stopped). Block timestamps in contract mode gave exactly 2 s gaps in all measured windows, including around a seat transfer.
- **F-8 (info).** Gas: Active seat transfer about 504k (Net-A) and 520k (Net-T), Probation sale 346k, `setOperator` swap 58k (old rule), `selfSuspend` 129k, board vote 198k to 215k, activation about 349k.
