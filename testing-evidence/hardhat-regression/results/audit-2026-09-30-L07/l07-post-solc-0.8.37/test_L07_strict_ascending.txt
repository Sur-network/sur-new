=== L07-A — ترتیب صعودی اکید ===
✅ 1) آدرس تکراری [lo, lo] رد می‌شود
✅ 2) تکرار غیرمجاور با تجمیع‌نشدن [lo, hi, lo] رد می‌شود
✅ 3) ترتیب نزولی [hi, lo] رد می‌شود
✅ 4) ورودی صفربلاکی نامرتب هم رد می‌شود [lo, hi, mid:0] (کنترل پیش از skip)
✅ 5) هیچ‌کدام از ردها state را تغییر نداد (lastSettledBlock = 0، epochCount = 0)
✅ 6) فهرست مرتب و تجمیع‌شده [lo:60, hi:40] پذیرفته شد
✅ 7) مبلغ lo دقیقاً طبق فرمول برای ۶۰ بلاک (معادل جمع دو ورودی تکراری سابق، بدون گردکردن اضافه)  384000000000000000000 == 384000000000000000000
✅ 8) مبلغ hi دقیقاً طبق فرمول برای ۴۰ بلاک
✅ 9) رکورد epoch برای lo برابر ۶۰ (نه بازنویسی‌شده)
✅ 10) رکورد epoch برای hi برابر ۴۰
✅ 11) رکورد پاداش epoch برای lo برابر سهم پرداخت‌شده‌ی پاداش
✅ 12) دقیقاً یک رویداد ValidatorRewarded برای هر تولیدکننده (۲)
